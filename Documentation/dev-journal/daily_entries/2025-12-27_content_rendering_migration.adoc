== Technical Notes

=== Theme Change Flash Prevention

The PoC validated that using `QPalette` with `Qt::WA_UpdatesDisabled` attribute effectively prevents visible flash during theme changes. This approach:

1. Disables widget updates during palette change
2. Applies new palette colors
3. Re-enables updates
4. Forces single atomic repaint

This is significantly better than WebEngine's multi-process async updates.

=== HTML4/CSS 2.1 Limitations

* No CSS variables (`:root`, `var()`)
* No CSS3 features (transitions, transforms, etc.)
* Limited to HTML4 elements
* No JavaScript execution in content

These limitations are acceptable given:
* WYSIWYG editor will guide authors to compatible content
* QML provides richer interactive capabilities than JavaScript
* Better performance and no rendering flash

=== Synchronous Loading

QTextBrowser loads content synchronously, which means:
* `contentLoaded()` signal emitted immediately after `setHtml()`
* No need for `loadFinished` signal handling
* Simpler code flow
* Better performance (no async overhead)
