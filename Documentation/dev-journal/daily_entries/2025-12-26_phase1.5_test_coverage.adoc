== Technical Challenges

=== Database Connection Management

**Problem:** Tests were experiencing "connection still in use" warnings and query failures due to improper connection cleanup.

**Solution:**
- Added explicit `QSqlDatabase::removeDatabase()` calls after closing connections
- Added small delays (`QTest::qWait(10)`) to ensure connections are fully closed
- Used unique connection names for each database operation
- Ensured all queries complete before closing connections

=== Test Data Isolation

**Problem:** Tests were interfering with each other when using shared cartridge paths.

**Solution:**
- Used unique cartridge paths per test method
- Implemented DELETE + INSERT pattern for clean state management
- Added verification queries to confirm database state before assertions

=== Schema Completeness

**Problem:** Test cartridges were missing columns expected by `MetadataEditor`, causing query failures.

**Solution:**
- Updated `createMinimalCartridge()` to include all required columns
- Ensured test schema matches production schema expectations
