    app_name TEXT NOT NULL,

**QML Usage:**
QML embedded applications can now import and use the bridge:

[source,qml]
----
import SmartBook 1.0

Item {
    SmartbookBridge {
        id: bridge
        cartridgePath: "..."
        cartridgeGuid: "..."
        
        onFormDataSaved: function(formId, success, error) {
            // Handle form data save result
        }
    }
}
----

**Note:** Currently, `QmlEmbeddedAppWidget` uses `setContextProperty` to expose the bridge instance. The module registration allows QML to also instantiate `SmartbookBridge` directly if needed.
