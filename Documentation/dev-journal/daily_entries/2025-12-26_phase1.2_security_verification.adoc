== Implementation Details

=== SignatureVerifier Enhancements

**Status:** COMPLETE

Enhanced the `SignatureVerifier` class with proper certificate validation and signature verification:

*   **Certificate Validation:**
    *   Implemented `validateCertificate()` using `QSslCertificate` for real certificate parsing
    *   Added CA-signed vs self-signed detection (issuer == subject check)
    *   Implemented certificate expiration checking
    *   Expired CA certificates are downgraded to Level 2 (per DDD specification)
    *   Supports both DER and PEM certificate formats

*   **Digital Signature Verification:**
    *   Implemented `verifyDigitalSignature()` using OpenSSL EVP API
    *   Extracts public key from certificate using `QSslCertificate::publicKey()`
    *   Verifies signature against H1 hash using RSA PKCS#1 padding with SHA-256
    *   Matches the signing approach used in `CartridgeExporter`

*   **Public Key Fingerprint Verification:**
    *   Implemented `calculatePublicKeyFingerprint()` using SHA-256
    *   Implemented `verifyFingerprint()` for fingerprint comparison
    *   Detects certificate tampering via fingerprint mismatch

*   **Enhanced Phase 1 (Identity):**
    *   Updated `phase1_Identity()` to use real certificate validation
    *   Verifies fingerprint and digital signature during identity phase
    *   Properly determines security level (L1/L2/L3) based on certificate status

*   **Build System:**
    *   Added Qt6::Network component for `QSslCertificate`/`QSslKey` support
    *   Added optional OpenSSL support for signature verification
    *   OpenSSL is optional (gracefully degrades if not available)

=== ReaderViewWindow Security Integration

**Status:** COMPLETE

Integrated complete security verification workflow into `ReaderViewWindow`:

*   **Security Verification Workflow:**
    *   `performSecurityVerification()` implements 4-phase verification
    *   Step 1: Verify cartridge signature using `SignatureVerifier`
    *   Step 2: Handle tampering detection (H1 != H2)
    *   Step 3: Handle rejected policy (invalid signature, fingerprint mismatch)
    *   Step 4: Get cartridge metadata for consent dialog
    *   Step 5: Handle consent requirement for L2/L3 cartridges
    *   Step 6: Load content if verification passes

*   **Error Handling:**
    *   `handleSecurityError()` displays `SecurityErrorDialog` for violations
    *   Closes window on security errors (non-recoverable)
    *   Handles tampering, invalid certificate, and invalid signature errors

*   **Trust Registry Integration:**
    *   `handleConsentRequired()` shows `ConsentDialog` for L2/L3 cartridges
    *   Stores trust decisions based on user choices:
        *   "Load and Always Trust" → PERSISTENT trust
        *   "Load for This Session Only" → SESSION trust
        *   "Cancel" → no trust stored, window closed
    *   Checks trust registry to bypass consent for PERSISTENT trust

*   **Component Integration:**
    *   Added `SignatureVerifier` and `TrustRegistry` as member variables
    *   Integrated into `loadCartridge()` flow
    *   Proper cleanup and error handling
