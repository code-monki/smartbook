== Technical Challenges

=== Database Connection Management

**Problem:** `MetadataExtractor` used hardcoded connection names ("MetadataExtract", "HashCalc"), causing conflicts when multiple extractions happened in quick succession during tests.

**Solution:**
* Use unique connection names with UUIDs
* Properly close and remove connections after use
* Prevents "connection still in use" warnings and errors

=== Manifest Entry Updates for KeepBoth

**Problem:** When `KeepBoth` action was selected, the code tried to create a new manifest entry with the same GUID, causing a `ManifestFailed` error.

**Solution:**
* Check if manifest entry exists before creating
* For `KeepBoth`, update existing entry with new file path instead of creating duplicate
* Maintains single manifest entry per GUID while allowing multiple file copies

=== Query Column Handling

**Problem:** `MetadataExtractor` queried optional columns that might not exist in all cartridges, causing silent query failures.

**Solution:**
* Split query into required and optional columns
* Query required columns first (always present)
* Query optional columns separately (gracefully handles missing columns)
