== Purpose

This document provides essential context for a new AI agent session to quickly understand the current state of the SmartBook project, recent work, open issues, and next steps.

== Project Overview

SmartBook is a Qt6-based application for creating and reading digital publications in a SQLite-based cartridge format. The project is in Phase 1 implementation, focusing on:

* **Reader Application:** Multi-window content viewer with security verification
* **Creator Tool:** Authoring tool for creating and exporting cartridges
* **Security Model:** Three-tier trust system (L1: CA-signed, L2: self-signed, L3: unsigned)

=== Namespace Conventions

* **Creator classes:** `smartbook::creator` namespace
* **UI dialogs:** Also in `smartbook::creator` (NOT `smartbook::creator::ui`)
* **Exception:** Some UI classes may have `ui` subdirectory but still in `smartbook::creator` namespace

=== Common Issues and Solutions

1. **"Command failed to spawn: Aborted"**
   * This is a tool execution issue, not a code problem
   * Try running commands directly in terminal
   * May indicate conversation is too large - consider restarting agent

2. **Linker errors for PageManager methods**
   * Ensure `PageManager.cpp` is included in target sources
   * Check namespace matches between header and implementation

3. **PDF generation creates empty files**
   * Verify Chromium/Chrome is installed and detected
   * Check HTML files are valid and complete
   * Ensure `--virtual-time-budget` allows time for JavaScript execution
